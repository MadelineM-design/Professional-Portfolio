My Animations!

Animations

Animation Class

During this past year I have taken multiple animation classes and learned many different tools in Blender. Some of the tools were modeling, particles, fluids, armatures, inverse kinematics, modifers and many other simulations. On this page of my portfolio I will be showing some of the ones that I liked the best.

Refinement Project

This project was to make something out of a skill I had already learned from any previous classes. I chose to do a liquid simulation. In this animation I decided to make it look similar to a pool area as to not make the animation boring.

Research Project

In this project I had to chose one of the many different tools we learned with Blender. I chose to do camera mapping and tracking. I used a tutorial from Jacob Zirkle to show how to camera track.

Cookie Flex Rig Project

This project was to show off using the Cookie Flex Rig. It had to be an animation of the rig doing some sort of activity like dancing or an obstacle course. In mine I showed the character going through an obstacle course.

Moving Scene Project

This was one of my first final projects in my animations class. It was to recreate a scene from a popular show or movie and animate a character in it. I chose the show 'Liv and Maddie' for mine.
